# ViewMend Site Tracker

## Summary

Trigger ViewMend Site Tracker checks after TYPO3 content updates and deployments to catch unexpected website changes.

## Description

ViewMend is a website quality and operations platform. This extension connects TYPO3 to Site Tracker so teams can see whether content updates or deployments introduced unexpected website changes. It records public page and content lifecycle events plus explicit deployment markers, stores them locally, then sends them asynchronously through the official ViewMend SDK.

It understands TYPO3 workspaces, translations, scheduled visibility and multisite bindings. The native backend module provides connection setup, event rules, operational readiness and delivery Activity with retry/run/cancel actions. Tokens are environment-backed or write-only encrypted values; content bodies, editor data, cookies and request payloads are never sent.

## Search terms

TYPO3 website change monitoring; TYPO3 deployment monitoring; TYPO3 Site Tracker integration; site operations; asynchronous delivery; ViewMend.

## Compatibility

TYPO3 13.4 and 14.3; PHP 8.3–8.5. MariaDB is the verified database target.
