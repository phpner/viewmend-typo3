# ViewMend Site Tracker

## Summary

Official ViewMend integration for confirmed TYPO3 website changes and duplicate-safe deployment monitoring, with a local asynchronous queue and native backend operations.

## Description

ViewMend is a website quality and operations platform. This extension connects TYPO3 to its Site Tracker module. It records confirmed public page/content lifecycle changes and explicit deployment markers, stores them locally, then sends them asynchronously through the official ViewMend SDK.

It understands TYPO3 workspaces, translations, scheduled visibility and multisite bindings. The native backend module provides connection setup, event rules, operational readiness and delivery Activity with retry/run/cancel actions. Tokens are environment-backed or write-only encrypted values; content bodies, editor data, cookies and request payloads are never sent.

## Search terms

## Compatibility

TYPO3 13.4 and 14.3; PHP 8.3–8.5. MariaDB is the verified database target.
