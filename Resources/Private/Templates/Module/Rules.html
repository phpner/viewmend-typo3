Deployment markers

Use vendor/bin/typo3 viewmend:deployment <stable-event-id> in the deployment pipeline. The command queues locally and returns a non-zero exit code for invalid configuration or input.

Extension installation, updates and removal require an explicit deployment marker. Run the command after these operations complete.
